# Security policy

## How to report a vulnerability

**Do not open a public issue** for security flaws. Use GitHub's private reporting:

1. Open the repository's [Security](https://github.com/Epaminondaslage/geradorOne/security) tab.
2. Click **Report a vulnerability**.
3. Describe the problem: what happens, how to reproduce it, and the impact you see.

The report is visible only to the project maintainers. Do not include passwords, API keys, or data of real people; if you need an example, use test data.

## What happens next

- Confirmation of receipt comes through the report itself.
- We assess the impact, fix it, and publish the fix. We agree with you on when to disclose the problem.
- If you wish, we credit your name in the fix notice.

## Supported versions

Only the version on the `main` branch receives security fixes.

## Out of scope

Instances hosted by third parties: talk to whoever administers the instance.
